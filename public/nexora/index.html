About the Project

Nexora AI is a second-year IT college mini project that demonstrates how Generative AI and gamification can improve self-learning. Students enroll in a course, set a personal goal, follow an AI-generated learning path, attempt quizzes, earn XP and streaks, and finally redeem reward points.

  • Personalized learning paths
  • Quizzes with instant scoring
  • Progress analytics with charts
  • Rewards, badges and leaderboard
